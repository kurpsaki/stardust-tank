# stardust-tank

A dark theme for the Claude desktop app. Behind the conversation, fine ASCII stardust drifts in three layers of depth (tiny and dim far away, larger and brighter up close), and bright stars twinkle here and there. A goldfish rendered from real footage into fine ASCII swims across, stops partway, turns around and swims back, while a smaller one passes the other way and bubbles drawn in fine characters rise and wobble. The middle of the screen stays dark so your text is always the brightest thing on it.

The backdrop also follows Claude: when you send a message, the stardust flares up twice and fine dust bursts here and there across the screen; while Claude works, the stardust and stars stay brighter; when the turn ends, it settles again. The fish and the stars carry on from where they were, even when the app redraws the backdrop.

- Dark mode only. Text contrast comes first: the panels are frosted over the backdrop, and body text sits well above 7:1.
- With "reduce motion" turned on, everything stands still.
- The backdrop is drawn in the desktop app only (as in the official theme examples); the terminal and editor extensions do not draw themes.

## Install

Type these at the Claude Code prompt (the desktop app takes them too), one after another:

```
/plugin marketplace add kurpsaki/stardust-tank
/plugin install stardust-tank@stardust-tank
/reload-plugins
```

The backdrop is drawn in the desktop app, in sessions that run on this computer (not in cloud environments). To turn it off, disable or uninstall the plugin (`/plugin`) and start a new session.

## Change the scene

`hooks/scene.js` is generated by `tools/gen-scene.mjs` (background, speeds, colors of the fish), which reads the goldfish frames in `tools/fish-frames.json`:

```bash
node tools/gen-scene.mjs
```

To make the goldfish from other footage (a single goldfish on a black background, facing right: one clip swimming in place, one turning around), regenerate the frames first. The videos themselves are not part of this repository.

```bash
node tools/fish-video.mjs <loop.mp4> <turn.mp4>
```

The scene, including the sparkle added while Claude works, has to stay under about 127,700 characters: above that the desktop app quietly swaps the backdrop for a still frame, even though its documented limit is 131,072. The generator prints the size and `claude plugin test .` checks it, along with the other things that make the app freeze the backdrop (`<use>`, animations that do not repeat forever, `@media` rules other than `prefers-reduced-motion`). UI colors live in `hooks/palette.js`.
